# SK Telecom

> SK Telecom Co., Ltd. is South Korea's largest mobile network operator and the telecom arm of SK Group. Its public developer surface is SK open API (openapi.sk.com) — a self-serve portal for AI, big-data and mobility product APIs, not for network APIs. Every API is fronted by one AWS API Gateway at apis.openapi.sk.com and authenticated with a portal-issued `appKey` request header over HTTPS. SK Telecom is a CAMARA participant and GSMA Open Gateway signatory, but no CAMARA endpoint (Number Verification, SIM Swap, KYC Match, Quality on Demand) is callable from any host SK Telecom operates; those reach developers only through aggregators.

## APIs with machine-readable contracts

- [SK Telecom A.X TTS API](https://openapi.sk.com/products/detail?svcSeq=67): Korean text-to-speech on SKT's own DNN models. Base https://apis.openapi.sk.com/axtts. 3 operations.
- [SK Telecom A. facecan API](https://openapi.sk.com/products/detail?svcSeq=50): Face database, detection, recognition and landmarks. Base https://apis.openapi.sk.com/nugufacecan. 12 operations.
- [SK Telecom Puzzle Place Congestion API](https://openapi.sk.com/products/detail?svcSeq=56): Real-time and historical place/commercial-area congestion and visitor analytics from mobile network signalling. Base https://apis.openapi.sk.com/puzzle/place. 16 operations.
- [SK Telecom Puzzle Residence API](https://openapi.sk.com/products/detail?svcSeq=66): Apartment-complex resident analytics keyed on kaptCode. Base https://apis.openapi.sk.com/puzzle/residence. 5 operations.
- [SK Telecom META API](https://meta-skopenapi.readme.io/reference/lpr-1): Video/image analysis — golf swing, pose estimation, licence plate recognition. Base https://apis.openapi.sk.com/sigmeta. 7 operations.
- [SK Telecom OVS API](https://ovs-skopenapi.readme.io/): Road-event alerting to registered devices. Base https://apis.openapi.sk.com/api/ovs. 12 operations. SERVICE TERMINATED 2026-04-07 13:00 KST.

## How to call these APIs

- Authentication: `appKey` request header (lowercase `appkey` on the Puzzle APIs), issued from https://openapi.sk.com/mypage/project/. No OAuth, no OIDC, no mTLS. A. facecan additionally requires `app-id`; OVS additionally requires `X-Authorization`.
- Transport: HTTPS only. Port 80 was closed on 2026-07-01 with no redirect.
- Errors: proprietary envelope `{"error":{"id","category","code","message"}}` at the gateway; `{"message","code"}` inside products. Not RFC 9457. See [errors](errors/sk-telecom-error-codes.yml).
- Rate limits: HTTP 429 `THROTTLED` (call rate) and `QUOTA_EXCEEDED` (plan quota). No rate-limit headers. See [rate limits](rate-limits/sk-telecom-rate-limits.yml).
- Idempotency: not supported and not documented anywhere.
- Events: no webhooks, no AsyncAPI, no streaming surface.
